# 配料表日期生成器

一个给 Windows 使用的桌面小工具：把一批配料表图片作为模板，选择日期后自动写入生产日期，并按日期创建文件夹保存。

## 推荐工作流

现在程序包含 **模板准备 + 手动生成 + 每日自动生成** 三个环节。

### 0. 第一次：从历史成品生成 32 张无日期模板

如果手头只有已经带日期的历史成品，不需要再手工截图 32 次。

1. 打开程序；
2. 点击 **“没有无日期模板？从历史成品一键生成…”**；
3. 选择一个历史日期文件夹，例如 `10月1日`，里面应有约 32 张图片；
4. 程序会在它的上一级目录自动创建 `无日期模板`；
5. 程序只清除日期字符串本身，保留原始“生产日期:”与“保质期:3天”；
6. 生成完成后，这套无日期模板会被自动选中，可以马上测试新日期。

模板清除区域已经按现有“自营配料表”历史成品重新收紧，同时改成只擦除深色日期笔画，不再整块填白，避免白色矩形遮住旁边原文字。

### 1. 手动模式

适合临时生成某一天，或者一次生成未来几天：

1. 确认已经选中 `无日期模板` 文件夹；
2. 选择输出文件夹；
3. 选择日期；
4. 右侧预览确认日期位置；
5. 点击“手动开始生成”。

例如选择 `2026-10-01`，会生成：

```text
自动生成结果/
  10月1日/
    配料表1.png
    配料表2.png
    ...
```

日期格式按现有历史成品设置为：

```text
2026 年 10 月 01 日
```

如果位置或字号被旧版本配置影响，可以点击 **“恢复推荐参数”**。

### 2. 每日自动模式

第一次先选好无日期模板文件夹、输出位置并校准日期位置，然后：

1. 输入运行时间，例如 `06:00`；
2. 点击“安装 / 更新自动任务”。

程序会使用 Windows 任务计划程序，每天到点自动生成当天的全部模板图片。

如果当天图片已经存在，自动模式会跳过已有文件，不会重复覆盖；如果上次只生成了一部分，再次运行时会补齐缺失图片。

> 自动任务依赖当前 EXE 或本地项目路径。移动项目后请重新安装一次自动任务。

## 现在能做什么

- 从一整套历史成品自动生成无日期模板
- 支持 PNG / JPG / JPEG / BMP / WEBP
- 单日生成或日期范围批量生成
- 自动创建 `10月1日`、`10月2日` 等文件夹
- 每个日期文件夹生成全部模板图片
- 原始历史成品与无日期模板均不被日常生成流程修改
- 可预览任意模板
- 可直接点击预览图设置日期起点
- 可微调 X / Y / 字号，并选择粗体
- 提供“恢复推荐参数”
- 自动寻找 Windows 中文字体
- 手动模式默认防止误覆盖
- 自动模式可安全重复运行并补齐缺失文件
- 模板路径、输出路径和校准参数会保存到本机
- 支持 Windows 每日定时自动生成

## 本地测试

第一次：

```text
setup_local.bat
```

之后每次测试：

```text
run_local.bat
```

测试“自动生成今天”：

```text
run_auto_today_local.bat
```

开发阶段不需要反复打包 EXE。

## 项目结构

```text
app.py
label_date_generator/
  auto.py        # 每日自动生成与 Windows 任务计划
  core.py        # 模板准备、图片渲染、批量生成
  settings.py    # 本机配置保存与旧配置迁移
  ui.py          # Windows 桌面界面
tests/
  test_core.py
setup_local.bat
run_local.bat
run_auto_today_local.bat
build_windows.bat
.github/workflows/build-windows.yml
```

## 本地运行

需要 Python 3.10+：

```bash
pip install -r requirements.txt
python app.py
```

自动生成今天：

```bash
python app.py --auto-today
```

## 运行测试

```bash
python -m unittest discover -s tests
```

## 打包 Windows EXE

双击：

```text
build_windows.bat
```

或者手动执行：

```bash
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name "配料表日期生成器" app.py
```

生成结果：

```text
dist/配料表日期生成器.exe
```

## 安全与隐私

仓库只需要保存程序代码。真实的 32 张配料表图片不需要上传 GitHub，程序直接读取电脑本地文件夹即可。
