# 配料表日期生成器

Windows 桌面小工具：保留原始配料表图片不变，在固定位置自动写入“生产日期”，并按日期创建输出文件夹。

## 第一版功能

- 选择包含配料表模板图片的文件夹（支持 PNG/JPG/JPEG/BMP/WEBP）
- 选择输出目录
- 单日生成，或按起止日期批量生成
- 自动创建 `10月1日`、`10月2日` 等文件夹
- 每个日期文件夹生成全部模板图片
- 右侧实时预览第一张模板的日期效果
- 日期坐标可在界面中用 X/Y 百分比校准
- 自动寻找 Windows 中文字体，避免中文乱码
- 原图永不覆盖

## 运行

需要 Python 3.10+：

```bash
pip install -r requirements.txt
python app.py
```

## 使用建议

首次拿到客户的 32 张原始模板后：

1. 选择模板文件夹；
2. 在右侧预览日期；
3. 调整“日期位置 X/Y”直到文字准确落在“生产日期：”后的空白处；
4. 选择单日或日期范围；
5. 点击“开始生成”。

坐标使用图片宽高百分比，因此同一版式、不同分辨率的图片也能保持相对位置。

## 打包 Windows EXE

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --name "配料表日期生成器" app.py
```

生成结果位于 `dist/配料表日期生成器/`。

> 当前默认坐标依据示例截图预设。正式交付前建议用一张原始模板校准一次位置与字号。
