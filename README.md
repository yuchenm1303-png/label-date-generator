# 配料表日期生成器

用于批量给配料表图片添加生产日期的 Windows 桌面工具。当前主版本采用 **Electron + React + TypeScript + Vite** 界面，图片处理使用 Python + Pillow。

## 当前工作流

### 第一次：准备 32 张无日期模板

如果手里只有已经带日期的历史成品，不需要再人工截图 32 次。

1. 打开程序；
2. 点击 **“没有无日期模板？从历史成品一键生成”**；
3. 选择一个已有日期的成品文件夹，例如 `自营配料表\10月1日`；
4. 程序会在同级自动创建 `无日期模板`；
5. 旧日期只会在日期字符串范围内被清除，保留左侧“生产日期:”和右侧“保质期:3天”；
6. 新生成的 32 张模板会自动载入程序。

模板准备会使用原图附近的背景色清除旧日期，避免出现明显的白色遮挡块。

### 日常手动生成

1. 确认程序已选中 `无日期模板`；
2. 选择输出位置；
3. 选择单日或日期范围；
4. 在右侧预览确认日期位置；
5. 点击生成。

日期格式按现有历史成品统一为：

```text
2026 年 10 月 01 日
```

输出文件夹按日期创建：

```text
自动生成结果/
  10月1日/
  10月2日/
  ...
```

## 文件名规则

**生成后的每张图片文件名必须与对应产品名保持一致。**

程序不会给文件名追加日期、序号或其他后缀，而是完整保留模板图片的文件名。例如：

```text
豆可滋   白干   净含量 2斤.png
豆可滋   嫩豆腐   净含量 5斤.png
豆小滋  嫩豆腐  净含量 12斤.png
```

因此，只要历史成品/模板图片本身按产品名命名，之后每天生成的图片也会继续保持同样的产品名。

## V2 界面

- Electron + React 桌面界面
- 一次处理整个模板文件夹（例如 32 张）
- 可从历史成品一键生成无日期模板
- 支持单日和日期范围
- 可前后切换查看全部模板
- 可直接点击预览图片定位日期
- 可精确调整 X / Y / 字号
- 默认参数已按现有自营历史成品校准
- 生成过程显示实时进度
- 原始图片不会被日常生成流程修改
- 所有图片只在本机处理

## 本地开发运行（推荐测试方式）

需要 Node.js 20+ 与 Python 3.10+。

```bash
pip install -r requirements.txt
npm install
npm run dev
```

开发模式会直接打开桌面窗口。修改代码后重新运行/刷新即可，不需要每次打包 EXE。

## 正式构建

```bash
npm run build
npm run start
```

## Windows 安装包

```bash
npm run package:win
```

开发和内部测试阶段建议继续使用 `npm run dev`。

## 分支约定

当前项目后续开发 **直接在 `main` 分支进行**，不再为日常修改单独创建开发分支。
